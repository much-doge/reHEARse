# Design system: Quiet Signal

## Design intent

The interface should feel like a calm listening desk, not an exam portal or a
dashboard of judgments. Warm paper surfaces, deep ink, and one electric accent
support attention without mimicking TOEFL branding.

## Visual tokens

- canvas: warm mist `#f3f0e8`;
- surface: paper `#fffdf7`;
- ink: midnight `#17202a`;
- muted ink: slate `#62706f`;
- accent: signal blue `#3164f4`;
- growth: leaf `#1f7a5a`;
- reconsider: clay `#b25f3f`;
- borders: `#d9d7cf`;
- display type: Fraunces or a high-contrast serif fallback;
- interface type: Geist/Inter or a clean system sans;
- generous rounded corners, but avoid generic floating-card overload.

## Interaction language

Use neutral states: Captured, Unclear, Reconsider, Newly noticed, and Not enough
evidence. Never Strong/Weak, Pass/Fail, percentage-complete, or traffic-light
mastery.

English is shown first with Indonesian immediately paired beneath it in a
quieter style. A later locale preference may reverse emphasis, but both remain
available for critical feedback.

## Primary screen

The learning screen uses three zones:

1. a restrained audio rail with playback and listen count;
2. a roomy notebook split between free notes and reconstruction;
3. after submission, a feedback “signal” with observations and one prominent
   next-listen target.

Attempt history is a chronological notebook, not a rising progress chart.
