## Files and modifications

`public/art/avatars/parts/` contains only the 136 PNGs referenced by the
catalogue's available bodies, arms, legs, accessories, eyes and mouths. Files
were copied byte-for-byte from `PNG/Default/` in the archive; filenames were
preserved. The application does not modify those source PNGs.

reHEARse combines the parts into 30 original character arrangements in SVG and
adds CSS-authored blink, wave, step, accessory, body and shadow movement. The
standalone HTML gallery repeats those rendering recipes solely as a review
artefact. It does not create a second runtime asset source.
